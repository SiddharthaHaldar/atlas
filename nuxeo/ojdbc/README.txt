Place ojdbc6.jar in this directory before starting the containers.

The jar is not included in version control due to Oracle's licensing restrictions.

Download ojdbc6 11.2.0.4 from Maven Central:
https://repo1.maven.org/maven2/com/oracle/database/jdbc/ojdbc6/11.2.0.4/ojdbc6-11.2.0.4.jar

Or via curl:
curl -L https://repo1.maven.org/maven2/com/oracle/database/jdbc/ojdbc6/11.2.0.4/ojdbc6-11.2.0.4.jar -o ojdbc6.jar
